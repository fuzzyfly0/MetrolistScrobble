## What's new

### Start and end points per song
- **Start point A:** a song starts playing at A instead of the beginning, for example to skip a long intro
- **End point B:** when B is reached, playback moves on to the next song (or repeats from A with *Repeat one*), for example to skip a long outro or silence
- Set or clear A and B with the new buttons in the player, in Android Auto and in the media notification; the points are saved per song
- **Previous** respects A: within the first seconds after A it goes to the previous song, otherwise it jumps back to A

### Translations
- German texts for the start and end point actions

Install over 0.2.2 to keep your settings and playlist. The app database is upgraded automatically.
