## What's new

### Recording
- **Work profile support:** YouTube Music is now also detected through its media notification, so recording works when YouTube Music runs in a work profile and Metrolist Scrobble in the personal profile
- **Other music apps:** Spotify, Apple Music, Amazon Music, Deezer, TIDAL and SoundCloud can be recorded too, each with its own switch. The regular YouTube app is never recorded
- **Adjustable listen time:** choose how long a song has to play before it is added (5 to 240 seconds, default 30, at most 90 % of the song)

### Playlist
- **New name:** the playlist is now called *Played in other apps*, the integration *Other apps' listening history*. An existing playlist with an old name is renamed automatically
- **Insert order:** new songs can go to the top or the bottom of the playlist
- **Maximum size:** keep at most a set number of songs; the oldest are removed first
- **Clear playlist:** remove all recorded songs from the settings
- **Automatic downloads:** download every recorded song so it plays offline
- **Survives restores:** after a backup restore or playlist import, an existing playlist with the recorder's name is picked up again instead of creating a new one

### Android Auto
- The recorder playlist can be shown as its own entry in the Android Auto menu (*Settings → Android Auto*)
- Menu sections added in newer versions no longer go missing when the order was saved before

### Settings
- **Last activity** shows what was detected or added most recently, to check that recording works

## Setup

*Settings → Integrations → Other apps' listening history*: turn it on and grant notification access.

Install over 0.1.0 to keep your settings and playlist.
